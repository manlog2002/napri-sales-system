# نطاق تسليم NAPRI Delivery V1

## الهدف

نسخة خاصة قابلة للتجربة التشغيلية اليومية على Sites، تدير العميل والطلب والسعر والمخزون والتحصيل والصلاحيات بسجل مراجعة واضح.

## المشمول

- دخول ChatGPT ومستخدم تأسيسي واحد بصفة مدير.
- أدوار إدارة وموظف وعميل مع تحقق الصلاحية داخل الخادم.
- عزل بيانات العميل وربط حساب العميل بسجله التجاري.
- إدارة المنتجات والعملاء والمستخدمين من واجهة الإدارة.
- طلب برقم مرجعي، مفتاح منع تكرار، وأسعار متحقق منها على الخادم.
- بيانات التواصل وعنوان التسليم وملاحظات الطلب.
- انتقال حالة الطلب بالتسلسل حتى التسليم.
- تحصيل لا يتجاوز الرصيد المسجل.
- حركة مخزون لكل بيع أو تسوية ومنع الرصيد السالب.
- اعتماد أو إيقاف قائمة الأسعار من الإدارة.
- سجل تدقيق للعمليات الحساسة.
- ترحيل D1 واختبارات بناء ومخرجات.

## غير المشمول في V1

- استيراد كامل لملف Excel القديم قبل اعتماد الملكية والتنظيف والمطابقة.
- الفاتورة الضريبية والتكامل المحاسبي الرسمي.
- الدفع الإلكتروني أو WhatsApp Business أو إرسال حملات.
- تحسين المسار الجغرافي وGPS.
- تنبؤ آلي مدرب أو ذكاء اصطناعي تنفيذي.
- موقع عام أو وصول غير مقيد.

## معيار التسليم

يعد الإصدار صالحًا للتجربة عندما تنجح أوامر `npm run lint` و`npm run build` و`npm test`، يرفع commit نفسه إلى المستودع الخاص، ينشر إصدار Sites الخاص، ثم تنفذ قائمة قبول المستخدم دون أعطال حرجة.
