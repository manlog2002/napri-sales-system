# قائمة قبول المستخدم — NAPRI Delivery V1

نفذ القائمة على بيانات تجريبية قبل اعتماد التشغيل الحقيقي.

## الدخول والصلاحيات

- [ ] المدير يرى كل الأقسام ويفتح «إدارة البيانات».
- [ ] الموظف لا يستطيع فتح وظائف الإدارة أو تعديل الصلاحيات والأسعار.
- [ ] العميل يرى طلباته وسجله المرتبط فقط.
- [ ] بريد غير مضاف يرفض من واجهة API ولا يحصل على بيانات.

## المنتجات والمخزون

- [ ] إضافة SKU جديد تظهر بعد إعادة التحميل.
- [ ] تسوية موجبة أو سالبة صحيحة تسجل بسبب واضح.
- [ ] تسوية تجعل المخزون سالبًا ترفض.
- [ ] طلب يتجاوز المخزون يرفض دون إنشاء طلب أو حركة ناقصة.

## الطلبات

- [ ] الطلب الداخلي يستخدم سعر الخادم ويولد رقم `NAP-...`.
- [ ] طلب العميل يتطلب الاسم ورقم التواصل والعنوان.
- [ ] زر الطلب الخارجي يتوقف والقائمة «مسودة».
- [ ] اعتماد الأسعار يتيح الطلب الخارجي.
- [ ] تحديث الحالة يقبل الخطوة التالية فقط ولا يسمح بالتراجع.
- [ ] إعادة إرسال الطلب بالمفتاح نفسه لا تنشئ نسخة ثانية.

## العملاء والتحصيل

- [ ] إضافة أو تحديث العميل بالكود تعمل.
- [ ] ربط بريد عميل بسجله يعرض سجله وحده.
- [ ] التحصيل الصحيح يخفض الرصيد.
- [ ] تحصيل أعلى من الرصيد يرفض.

## الاستلام

- [ ] سجل التدقيق يحتوي العمليات الحساسة الأخيرة.
- [ ] الاختبارات الآلية ناجحة.
- [ ] رابط Sites خاص ويطلب حسابًا مصرحًا.
- [ ] صاحب القرار يوقع اعتماد البيانات والأسعار قبل التشغيل الفعلي.
