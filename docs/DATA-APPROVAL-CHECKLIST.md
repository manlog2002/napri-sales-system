# قائمة اعتماد بيانات نبري

حالة قاعدة البداية: **تجريبية وغير معتمدة للتشغيل المالي**.

## قبل استيراد Excel

- [ ] تأكيد أن الملف يخص شركة نبري وأن استخدام بياناته مصرح.
- [ ] حفظ نسخة أصلية للقراءة فقط مع بصمة وتاريخ استلام.
- [ ] اعتماد الاسم الرئيسي لكل كود عميل مكرر أو متعارض.
- [ ] توحيد المناطق والمندوبين والوحدات وأسماء المنتجات.
- [ ] فصل البيع والتحصيل والمديونية بدل الصيغ الدائرية.
- [ ] تحديد هل الأسعار تاريخية أم حالية.
- [ ] إزالة أو حماية الهواتف والعناوين غير اللازمة.

## قبل التحويل إلى تشغيل فعلي

- [ ] مطابقة رصيد كل عميل مع كشف معتمد.
- [ ] جرد افتتاحي فعلي لكل SKU.
- [ ] اعتماد السعر ووحدة البيع والعبوة وحد إعادة الطلب.
- [ ] تحديد الأدوار والبريد لكل مستخدم.
- [ ] تجربة استيراد على نسخة غير إنتاجية ومراجعة تقرير الفروق.
- [ ] اعتماد كتابي من صاحب القرار على العملاء والأسعار والأرصدة والمخزون.

لا يغير النظام `data_profile` من `demo` إلى تشغيل فعلي تلقائيًا؛ يتم ذلك فقط ضمن ترحيل بيانات مستقل ومعتمد.
