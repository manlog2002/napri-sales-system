# نظام نبري للمبيعات والتوزيع

مستودع خاص يجمع كود نظام نبري، إعدادات قاعدة البيانات والاستضافة، الاختبارات، مستندات البيع والتعاقد، دليل الاستخدام، العرض التقديمي، الفيديوهات ومواد التسليم.

> **سري — للاستخدام الداخلي في شركة نبري.** يحتوي النموذج التشغيلي على أسماء عملاء ومندوبين وإشارات مبيعات وتحصيل. لا تحوّل المستودع أو الموقع إلى وصول عام قبل استبدال البيانات التجريبية/التاريخية ومراجعة سياسة الخصوصية.

## NAPRI Delivery V1

- دخول خاص بهوية ChatGPT وصلاحيات فعلية على الخادم: إدارة، موظف، وعميل.
- عزل طلبات وبيانات كل عميل وربط حسابه بسجل العميل من لوحة الإدارة.
- الطلبات بأرقام مرجعية، حماية من التكرار، وبيانات اتصال وعنوان تسليم.
- دورة حالة متسلسلة من التسجيل حتى التسليم.
- قائمة أسعار موحدة بحالة «مسودة/نشطة» واعتماد إداري صريح.
- مخزون محمي من الرصيد السالب مع سجل حركات وتسويات موثقة.
- العملاء، التحصيل والأرصدة وإدارة البيانات الرئيسية من داخل النظام.
- سجل تدقيق للطلبات والتحصيل والمخزون والأسعار والصلاحيات.
- وظائف المرحلة التالية تظهر بمتطلبات تفعيل واضحة ولا تنفذ إرسالًا خارجيًا.

النسخة المنشورة تبقى خاصة. بيانات البداية موسومة كتجريبية ولا تتحول إلى بيانات تشغيل معتمدة إلا بعد تنفيذ [قائمة اعتماد البيانات](docs/DATA-APPROVAL-CHECKLIST.md).

## التشغيل المحلي

المتطلبات: Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

ثم افتح: `http://localhost:3000`

## التحقق

```bash
npm run build
npm test
npm run lint
```

## بنية المستودع

- `app/`: واجهات النظام وواجهة حفظ الطلبات والتحصيل.
- `db/` و`drizzle/`: تعريفات قاعدة البيانات والترحيلات.
- `worker/`: نقطة تشغيل Cloudflare.
- `.openai/hosting.json`: إعداد مشروع الاستضافة المؤقتة.
- `tests/`: اختبارات البناء والمخرجات.
- `docs/`: نطاق التسليم، دليل التشغيل، قبول المستخدم واعتماد البيانات.
- `deliverables/sales-kit/`: العرض التجاري، مسودة الاتفاقية، دليل الاستخدام، الكتيب والفيديوهات.
- `deliverables/ميلاد-نظام-نبري-المرحلة-الأولى.pptx`: عرض ميلاد النظام.
- `archives/`: نسخة أرشيفية من إصدار الموقع.
- `materials/system-screenshots/`: صور الواجهات المستخدمة في الشرح.
- `tooling/`: أدوات إعادة إنشاء المستندات والفيديو والعرض.

## حالة المستندات

- العرض التجاري والدليل والكتيب والفيديوهات: مواد تنفيذية جاهزة للمراجعة والعرض.
- اتفاقية التوريد والترخيص: **مسودة** تحتاج استكمال بيانات الطرفين، السعر، الضرائب، الدولة والقانون المختص، ثم مراجعة قانونية قبل التوقيع.

## ضوابط الأمان

- لا تُرفع ملفات `.env` أو المفاتيح أو كلمات المرور.
- لا تُرفع `node_modules` أو ملفات البناء المؤقتة.
- تُحفظ بيانات العملاء والمبيعات داخل مستودع خاص فقط.
- يجب استخدام متغيرات البيئة للأسرار في أي نشر لاحق.
- أول مستخدم مصرح له في موقع Sites الخاص يُسجل مديرًا تأسيسيًا؛ بعد ذلك لا يدخل النظام إلا المستخدمون الذين تضيفهم الإدارة.
- لا تفعل قائمة الأسعار للبيع الخارجي قبل اعتماد الأسعار والمخزون من صاحب القرار.
